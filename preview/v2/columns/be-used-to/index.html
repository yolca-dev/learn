be used to 〜ingの意味と使い方【例文つき】

〜に慣れている

「be used to 〜ing」は「〜に慣れている」という意味。ある物ごとが当たり前になって、ふつうに感じられるときに使います。

1意味

いつもそうなので、もう特別なことに感じない、という状態を言います。あとには名詞か 〜ing を続けます。be used to the cold で「寒さに慣れている」。

2使う場面・相手

どんな場面で使えるか、例文と一緒に見てみましょう。

  1. 新しい学校や町の暮らしに慣れたかを話すとき。

    She wasn't used to the big city at first.

    彼女は、最初は大きな町に慣れていなかった。

  2. 早起きや寒さなど、ふだんのことに慣れていると言うとき。

    I'm used to getting up early.

    早起きには慣れている。

  3. 「まだ慣れていない」と言うとき。

    I'm still not used to taking the train to work.

    電車で通勤するのに、まだ慣れていない。

  • 「慣れる」と、慣れていく変化を言うときは get used to を使います。be used to は「慣れている」という状態です。あとに名詞か 〜ing を置くのは同じです。

    You'll get used to living alone.

    一人暮らしには、そのうち慣れるよ。

3例文

  • A

    A: Isn't it cold in here?

    A: ここ、寒くない?

    B

    B: Not really. I'm used to it.

    B: そうでもないよ。慣れてるから。

4似た表現・反対の表現との違い

be accustomed to
「〜に慣れている」。be used toとほぼ同じ意味で、言いかえられます。

5間違えやすいポイント

  • be used to のあとに、動詞の原形を置いてしまう間違いです(× We are used to go → ○ We are used to going)。動詞の原形を続けるのは、「前はよく〜した・前は〜だった(今は違う)」という used to do のほうです。形が似ているので、混ざりやすいところです。

6まとめ: この1文で覚えよう

I'm used to the noise now.

今はもう、その音に慣れている。

何かに慣れていると言うときに。
