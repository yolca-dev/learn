some と anyの使い分け

肯定文は some・否定文と疑問文は any が基本

目次

  1. 結論
  2. 使い分けの表
  3. それぞれの使い方
  4. 間違えやすいポイント
  5. 今日の表現を、忘れないうちに復習しよう

1結論

肯定文には some、否定文と疑問文には any を使うのが基本です。

ただし、何かを勧めるときのように答えが yes だと思っている疑問文では some を使います。また any は、肯定文で「どれでも」の意味にもなります。

something と anything、someone と anyone なども、同じように使い分けます。

2使い分けの表

語ふつう使う文型の例
some肯定文(疑問文では、yes を期待するとき)some milk / some friends / Would you like some tea?
any否定文・疑問文(「どれでも」の意味では肯定文)not any milk / any questions? / any book

3それぞれの使い方

some

some は「いくらか・いくつか」の意味で、数えられない名詞と複数形の名詞に使います(some milk / some friends)。数えられる名詞の単数形には付けません。

疑問文でも、答えが yes だと思っているときは some です。Would you like some tea? のように勧めるときや、Did you bring some snacks? のように、持ってきているはずだと思って聞くときがその例です。

the・these・my などが付いた名詞の前では、some of the answers のように of を入れます。any も同じです(any of these spices)。

some を強く読むと「ある〜」の意味になり、誰か・何かは分からないけれど、特定の人や物を指す言い方になります。

  1. お店で水を頼むとき。

    I'd like some water, please.

    お水をください。

  2. お茶を勧めるとき(yes を期待する疑問文)。

    Would you like some tea?

    お茶はいかがですか。

  3. 放課後のことを話すとき。

    I met some friends after school.

    放課後、友だちと何人か会った。

any

any は、否定文と疑問文で使うのが基本です。any だけでは否定の意味にならないので、not などと組み合わせます(I don't have any plans)。

not any と no は同じことを言えますが、no のほうが強い言い方です。

any を強く読むと「どれでもいい」の意味になり、こちらはふつう肯定文で使います。どんな種類の名詞にも使えます(any book)。

比較級の前に置いて、any faster(少しでも速く)のようにも使います。

  1. 週末の予定を聞かれたとき。

    I don't have any plans this weekend.

    今週末は、何も予定がない。

  2. 説明のあとで質問を受けるとき。

    Do you have any questions?

    何か質問はありますか。

  3. どれを選んでもいいと言うとき。

    You can choose any book on this shelf.

    この棚の本なら、どれを選んでもいいよ。

  4. 相手の歩くのが遅いとき。

    Can't you walk any faster?

    もうちょっと速く歩けないの?

someone・anything などの形

something と anything、someone と anyone、somebody と anybody、somewhere と anywhere も、some と any と同じように使い分けます。

someone と somebody、anyone と anybody は意味が同じで、-body のほうが少しくだけた言い方です。

  1. 玄関に人がいたと言うとき。

    I saw someone at the door.

    玄関に誰かいたよ。

  2. 変わったことはなかったと言うとき。

    I didn't see anything strange.

    変なものは何も見なかった。

4間違えやすいポイント

  • × I've got any ... / × I haven't got some ... → ○ I've got some ... / ○ I haven't got any ...「いくらか・いくつか」の意味では、肯定文に any、否定文に some は使いません。
  • × some brochure / × any hot meal → ○ a brochure数えられる名詞の単数形には、some や any ではなく a を使います。
  • 否定で短く答えるときに some を使ってしまう → ○ No, there weren't any.否定で短く答えるときも、any を使います。
  • × for some days → ○ for a few days「数日の間」と言うときは、some ではなく a few を使います。
  • × I have never seen something ... → ○ I have never seen anything ...never のような否定の意味の語のあとでは、something ではなく anything を使います。
